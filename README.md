# 魔女口袋

玻璃任务栏、小魔女和音乐舞台，让常用功能都在手边。

## 下载

[下载安装包：全功能版 / 精简版](https://github.com/wtolddd/magic-pocket/releases)

适用于 Windows 10 / 11（64 位）。安装时可选择位置，更新前请先从托盘正常退出旧版。

## 能做什么

- **玻璃任务栏**：切换外观样式、固定常用软件、查看窗口预览和切换窗口。
- **小魔女互动**：点击、摸头、拖动，打开应用抽屉。
- **快捷搜索**：查找应用、文件和文件夹。
- **音乐舞台**：查看曲名和专辑封面，控制播放、暂停、切歌与音量，支持拖动和关闭。
- **常用入口**：输入法、网络、系统托盘、系统设置和任务管理器。
- **全屏避让**：全屏时隐藏桌面界面，可选择静态或少动效。

## 两个版本

**全功能版**包含以上功能，以及 AI 助手、截图与屏幕取字、文件预览、贴纸、收纳篮、工作桌面和场景创作与分享。

**精简版**保留任务栏、小魔女、应用启动、基础搜索、音量和音乐控制。
