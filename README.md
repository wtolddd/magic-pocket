# 魔女口袋

**把常用软件、音乐和一只小魔女，放进桌面底部的口袋里。**

魔女口袋是一套 Windows 桌面工具。玻璃任务栏负责常用操作，小魔女陪你打开应用，音乐舞台让曲名、封面和播放按钮留在手边。外观、动效和舞台都可以按自己的习惯调整。

[下载安装包](https://github.com/wtolddd/magic-pocket/releases) · [查看更新](https://github.com/wtolddd/magic-pocket/releases/tag/v0.58.29) · [反馈问题](https://github.com/wtolddd/magic-pocket/issues)

适用于 **Windows 10 / 11，64 位**。

## 平时怎么用

### 常用软件，顺手打开

把常用软件固定到底栏，查看已打开窗口的缩略图，再点一下切换窗口。小魔女旁边的应用抽屉可以按游戏、办公、工具等分类整理，“未分类”也能改成自己的名字。图标同样支持右键重命名，重启后会保留，也可以恢复原名。

### 小魔女，也能帮你做点事

点击、摸头或拖动小魔女，展开带漫画气泡风格的应用抽屉。想清静一点时，可以选择少动效或静态显示。

### 找应用，不用记住全名

魔女速查支持中文、英文、全拼和首字母。比如要找“小魔女”，可以输入 `xiaomonv` 或 `xmn`；应用、文件和文件夹都能查找。

### 听音乐时，少切一次窗口

音乐舞台显示当前曲名和专辑封面，提供播放、暂停、上一首、下一首和音量控制。可以把它拖到顺手的位置，也可以随时关闭。曲目信息和按钮是否可用，取决于播放器提供的 Windows 媒体会话。

### 常用系统入口，也留在底栏

输入法、网络、系统托盘、系统设置和任务管理器都能从底栏打开。控制中心可以调整任务栏样式、动效、全屏避让和自动启动方式。

## 安装与更新

1. 下载并运行安装包，按提示选择安装位置。
2. 从 0.58.15 或更早版本更新时，先从托盘正常退出，再安装这一版。以后可以在“控制中心 → 更新与关于”下载新版，准备好后点“更新并重启”。
3. 启动后在控制中心选择外观、音乐舞台和动效。需要随开机使用时，再开启自动启动；也可以选择“登录即启动”。
